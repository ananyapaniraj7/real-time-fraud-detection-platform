# Sentinel

Sentinel is a real-time fraud detection platform built to simulate the backend architecture used by modern fintech companies and banks.

Instead of processing transactions synchronously, Sentinel is designed as an event-driven system where every financial transaction flows through multiple stages including validation, fraud detection, caching, machine learning, and real-time monitoring.

Goals:

- Learn production-grade backend architecture
- Understand distributed systems
- Build an interview-ready flagship project
- Learn Spring Boot, PostgreSQL, Kafka, Redis, Docker, React and Python ML
